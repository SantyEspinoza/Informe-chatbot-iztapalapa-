# Informe de Residencia Profesional — Chatbot Iztapalapa

Informe técnico de residencia profesional sobre el desarrollo de un chatbot para la página web de la Alcaldía Iztapalapa, con el objetivo de mejorar el acceso a trámites y servicios para los ciudadanos.

## Contenido

- Exploración de plataformas de IA: Landbot, OpenAI, Azure OpenAI, Character.AI, Rasa, Botfront
- Desarrollo del prototipo funcional en Landbot
- Pruebas técnicas en máquinas virtuales (Ubuntu Server 22.04)
- Integración con OpenAI API
- Propuesta de mejora para gobierno digital

## Herramientas evaluadas

| Herramienta | Estado |
|-------------|--------|
| Landbot | ✅ Prototipo funcional |
| OpenAI API | ✅ Prueba exitosa |
| Character.AI | ⚠️ Limitaciones de integración |
| Rasa / Botfront | ❌ Sin mantenimiento desde 2022 |

## Archivos

- `informe.pdf` — Documento completo del informe técnico

## Resultados

Se desarrolló un prototipo funcional en Landbot listo para implementación, con 4 secciones: Apoyos, Trámites y Servicios, Territoriales y Contacto. Se sentaron las bases para futuras implementaciones de IA en la alcaldía.
